完整备份（换电脑用）

          
把一个文件导出，其中包含全部服务商、模型、思考档位配置，以及已保存的 API Key。拿到另一台电脑后点“导入完整备份”即可，无需重新配置。

          
注意：该备份文件含有明文 Key，请存放在安全的地方，不要上传到网盘、GitHub 或聊天工具。

关于

        
ZCode Universal Model Gateway（ZUMG）

        

          
ZUMG 让 ZCode 只连接一个本地 OpenAI Responses 兼容端点，由网关把请求转发到多个服务商和模型。思考档位完全可配置，并会以 模型名@档位 这样的虚拟模型 ID 暴露出去。
